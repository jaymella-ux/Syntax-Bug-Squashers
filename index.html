How to play

  1. Read the code and tap the spot that looks wrong.
  2. Pick the correct fix from the choices below the code.
  3. Right answers score points. Back-to-back right answers build a combo (up to x5).
  4. A wrong tap or wrong choice costs a heart and breaks your combo.
  5. Fix every bug, then press Run code to clear the level.
  6. There are 9 levels: Easy, Medium, and Hard for HTML (orange), CSS (green), and JavaScript (magenta). Beat a level to unlock the next.
  7. Hard levels are fill in the blanks: a comment above each blank tells you what it does. Type the missing code in each box, then press Check code. Enter only moves to the next box.
  8. Hint: press Hint, then tap the bug (or blank) you want help with. It gives a clue (first letters and length), not the answer, and costs 50 points. Use another hint on the same spot for a bigger clue. You get 3 hints (5 on Hard levels).
  9. Keyboard: keys 1-4 pick a fix, H for a hint, P to pause, Enter to run the code.
