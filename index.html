How to play

  1. Read the code and tap the spot that looks wrong.
  2. Pick the correct fix from the choices below the code.
  3. Right answers score points. Back-to-back right answers build a combo (up to x5).
  4. A wrong tap or wrong choice costs a heart and breaks your combo.
  5. Fix every bug, then press Run code to see your output and clear the level.
  6. There are 9 levels: Easy, Medium, and Hard for HTML, CSS, and JavaScript. Beat a level to unlock the next.
  7. Hard levels give you almost-finished code and a short checklist. Fill in the missing pieces yourself, then press Check code. Each requirement turns green when you get it right, and you see your final output when all of them pass.
  8. Hint: press Hint, then tap the bug (or blank) you want help with. It gives a clue, not the answer, and costs 50 points. You get 3 hints (5 on Hard levels).
  9. Keyboard: keys 1-4 pick a fix, H for a hint, P to pause, Enter to run the code.
