How to play

  1. Read the code and tap the spot that looks wrong.
  2. Pick the correct fix from the choices below the code.
  3. Right answers score points. Back-to-back right answers build a combo (up to x5).
  4. A wrong tap or wrong choice costs a heart and breaks your combo.
  5. Fix every bug, then press Run code to clear the level.
  6. There are 9 levels: Easy, Medium, and Hard for HTML, then CSS, then JavaScript. Beat a level to unlock the next.
  7. Hard levels are fill in the blanks: type the missing code in each box, then press Check code. Enter only moves to the next box, so you won't lose a heart by accident.
  8. Hint shows one bug but costs 50 points. You get 3 hints (5 on Hard levels).
